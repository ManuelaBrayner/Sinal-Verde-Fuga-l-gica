# Sinal-Verde-Fuga-lógica


## Descrição:
### Desafie seu raciocínio sob pressão em uma perseguição urbana.
A bordo de um carro de fuga, seu objetivo é escapar da polícia atravessando uma avenida movimentada. O obstáculo: todos os semáforos dos cruzamentos estão travados no vermelho.

Para liberar a passagem, você deve resolver um problema de equivalência lógica antes que o tempo acabe. Cada acerto garante o sinal verde e mantém a vantagem sobre a viatura; um erro ou atraso permite que a polícia se aproxime.
